# Support

The portable package supports 64-bit Windows 10/11 with the .NET Framework 4.8 runtime. Inspection, backup, and import use the bundled `cct.exe`. Conversation deletion and legacy-sidebar repair require Codex CLI 0.148.0 or later; the latest CLI release is recommended.

Before opening an issue:

1. Confirm you are using the latest release.
2. Run the package's inspect step without writing.
3. Record the app version, Windows version, Codex version, backup extension, and the exact error text.
4. Reproduce with synthetic data when possible.

Never post a real backup package, session file, Codex database, username, private path, prompt, project source file, or secret. Redact screenshots before attaching them.
