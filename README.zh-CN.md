# Codex Conversation Migrator

**Codex 对话与项目管理、备份和迁移工具**

[English](README.md)

Codex Conversation Migrator 是一个本地运行的 Windows 桌面工具，用于统一管理 Codex 项目、主对话和子代理对话，并处理项目路径变更、存储空间清理、备份恢复及跨电脑迁移。

它不只是把对话文件从一处复制到另一处：工具会识别对话与项目的关联关系，在导入时重写项目路径、维护对话来源信息，并帮助 Codex 在目标项目下重新显示这些对话。

> 本项目是非官方社区工具，与 OpenAI 没有关联，也未获得 OpenAI 背书。Codex 的本地存储格式可能变化；正式导入前请先执行只读检查，并为重要数据保留独立备份。

## 它解决什么问题

| 使用场景 | 常见问题 | 本工具的处理方式 |
| --- | --- | --- |
| 同一台电脑移动或重命名项目 | 对话记录仍关联旧工作目录，打开新目录后可能无法在项目侧栏中看到原对话 | 将已有对话映射到新的项目目录，并更新本地任务索引和桌面项目归属 |
| 查看历史对话及磁盘占用 | 很难直观看到各项目、主对话和子代理对话的实际路径、最近更新时间及文件大小 | 按项目汇总，并将主对话与子代理分开列出；每条记录显示时间、大小和路径 |
| 清理大量子代理记录 | 子代理可能保存完整执行上下文、工具返回和终端输出，长期积累会占用较多 C 盘空间 | 支持多选、全选和批量删除子代理；可先移入软件回收站，也可永久清除 |
| 在多台电脑之间继续工作 | 项目文件和对话记录分开存放，手动复制项目后，对话未必能关联到新路径 | 可只迁移对话并关联到已复制的项目，也可将项目与全部关联对话一起打包迁移 |
| 在两台电脑之间往返 | 第二台电脑继续对话后，希望再迁回第一台电脑，而不是产生无法管理的重复副本 | 通过原始编号和目标项目识别同源对话，可将新增内容合并回已有对话 |

## 核心能力

### 对话与项目管理

- 显示项目目录、项目文件总大小以及文件数量。
- 分开管理主对话和子代理对话，避免两类记录混在一起。
- 显示每条对话的最近更新时间、会话文件大小、Thread ID 和实际路径。
- 只读查看主对话或子代理对话内容，不修改原会话。
- 在主对话和子代理页面使用一致的全选、全不选和删除所选操作。

### 项目改名、移动与重新关联

当项目在同一台电脑上改名或移动到新目录后，可以把该项目的对话备份为 `.codexchat`，再导入并选择新的项目目录。工具会重写对话中的工作目录信息，并定点更新 Codex 本地索引和桌面项目归属，使对话重新关联到新位置。

### 对话迁移或完整项目迁移

- **只迁移对话**：先自行复制项目目录，再使用 `.codexchat` 把选中的主对话迁入目标电脑并关联到该项目。
- **项目与对话一起迁移**：使用 `.codexproject` 将一个或多个项目目录、空目录、主对话和子代理对话打包到同一个文件。
- **往返迁移并继续合并**：电脑 A 迁移到电脑 B、在 B 上继续工作后，可再次备份并迁回 A；选择“按原始编号合并”即可在目标项目范围内识别同源对话并合并新增内容。
- **保留独立副本**：选择“作为新对话复制”时，每次都会生成新的 Thread ID 和独立会话文件，删除其中一份不会影响另一份。

### 查看、回收与删除

- 可将选中的对话移入软件回收站，之后恢复或永久删除。
- 可直接永久删除不再需要的主对话或子代理对话。
- 删除主对话时，可另外选择是否处理对应项目目录。
- 项目目录可移入 Windows 回收站，也可在明确确认后永久删除。

> **关于释放 C 盘空间：** 软件回收站位于 Codex 数据目录中，移入回收站主要用于防止误删，并不会明显释放该磁盘空间。确认不再需要记录后，还需从软件回收站永久删除，才会真正释放相应空间。

## 典型工作流

### 1. 同一台电脑移动或重命名项目

1. 为原项目选择需要保留的对话并创建 `.codexchat`。
2. 在“导入备份”中选择新的项目目录，并保持“把对话关联到上面的项目位置”开启。
3. 先执行“检查（不写入）”；检查通过后完全退出 Codex，再正式导入。
4. 重新打开 Codex 和新项目目录，确认对话已出现在该项目下。

### 2. 已经手动复制项目，只迁移对话

1. 在原电脑创建 `.codexchat`。
2. 将项目目录和 `.codexchat` 分别复制到新电脑。
3. 导入 `.codexchat`，并选择项目在新电脑上的实际目录。

### 3. 项目与对话一次性迁移

1. 选择一个或多个项目，创建 `.codexproject`。
2. 将这一个文件复制到目标电脑。
3. 选择项目还原位置，先检查，再导入项目文件与关联对话。

### 4. 迁移到另一台电脑使用后再合并回来

1. 在第二台电脑为同一项目重新创建备份。
2. 将备份带回第一台电脑并选择原项目目录。
3. 使用“按原始编号合并”；工具只在目标项目内查找同源记录，并合并后续对话内容。

## 备份格式

| 后缀 | 内容 | 适用场景 |
| --- | --- | --- |
| `.codexchat` | 所选主对话，不包含项目文件 | 项目已由用户自行复制、项目改名或移动、只归档对话 |
| `.codexproject` | 一个或多个项目目录，以及对应主对话和子代理对话 | 完整迁移项目工作环境 |
| `.codexpack` / `.codexbundle` | 旧版本兼容格式 | 只用于导入旧备份 |

`.cct-bak` 不是正式备份格式。它只是导入事务中的临时安全快照，成功提交或失败回滚后会自动清理。

## 快速开始

1. 从 Releases 下载 `CodexConversationMigrator-Windows-v3.0.0.zip`，并核对 SHA-256。
2. 将 ZIP 完整解压到同一个文件夹，不要拆开 EXE、XAML 和 `cct.exe`。
3. 双击 `Start.cmd` 或 `CodexConversationMigrator.exe`。
4. 根据需要选择“项目＋对话”或“仅对话”备份。
5. 导入时先检查；检查通过后完全退出 Codex，再正式写入。

## 源码编译

需要 Windows 10/11、.NET SDK 8.x、.NET Framework 4.8 Targeting Pack，以及 PowerShell 5.1 或更高版本。

```powershell
.\Get-Cct.ps1
.\build.ps1
.\test.ps1 -NoBuild
.\package.ps1 -Version 3.0.0
```

只有开发脚本 `Get-Cct.ps1` 会在缺少组件时下载固定版本的 `cct` v1.2.0，并在使用前校验压缩包和 EXE 的 SHA-256；桌面软件本身不会联网下载依赖。

## 隐私与安全

- 软件本地运行，没有遥测，也没有云同步。
- 备份文件可能包含提示词、源码、命令输出、本机路径和密钥，请按敏感文件保管。
- 永久删除无法从本工具恢复；执行前请确认对话和项目路径。
- 导入会更新 Codex 会话文件、本地任务索引和桌面项目归属。工具会创建安全备份并验证写入，但重要数据仍建议另行备份。
- 不要把真实备份包、JSONL 会话或 Codex 数据库上传到公开 Issue。

更多说明见 [PRIVACY.md](PRIVACY.md)、[SECURITY.md](SECURITY.md) 和 [备份格式说明](docs/BACKUP_FORMATS.md)。
