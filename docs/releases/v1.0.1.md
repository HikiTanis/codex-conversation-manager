# Codex Conversation Manager v1.0.1

Version 1.0.1 adopts a clearer, more searchable product name that matches the application's full scope: managing, inspecting, backing up, migrating, restoring, and deleting Codex conversations and projects on Windows.

## Changes

- Renamed the application from **Codex Conversation Migrator** to **Codex Conversation Manager**.
- Renamed the executable to `CodexConversationManager.exe` and the portable package to `CodexConversationManager-Windows-v1.0.1.zip`.
- Renamed the solution, source project, assembly, XAML resources, build scripts, CI artifacts, and public documentation consistently.
- Preserved existing app-trash data, transaction metadata, project/index safety backups, and conversation-lineage markers.
- Added fallback loading for the saved language preference from the previous application data directory.

## Compatibility

- End-user system: 64-bit Windows 10 or Windows 11 with .NET Framework 4.8.
- Inspection, preview, backup, and import use the built-in native engine and do not require Codex CLI.
- Conversation deletion and stale-sidebar repair require **Codex CLI 0.148.0 or later**; the latest compatible release is recommended.
- Existing `.codexchat`, `.codexproject`, `.codexpack`, and `.codexbundle` files remain compatible under the same rules as v1.0.0.

## Download and verification

Download both release assets:

- `CodexConversationManager-Windows-v1.0.1.zip`
- `SHA256SUMS.txt`

Verify the ZIP before extracting it:

```powershell
$zip = '.\CodexConversationManager-Windows-v1.0.1.zip'
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA-256 mismatch. Do not run this package.' }
$actual
```

Extract the package into a new folder rather than mixing files from the previous executable name. The application remains portable and unsigned; Windows may display an unknown-publisher warning.
