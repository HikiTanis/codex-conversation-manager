# Codex Conversation Migrator v1.0.0

Version 1.0.0 is the first public release of the local conversation-and-project management, backup, migration, and cleanup application. Inspection, backup, and import use a built-in native engine, and independently copied conversations receive separate IDs and files.

## 简体中文摘要

- 查看、正式备份和导入已改用软件内置原生引擎，不再需要单独的对话迁移程序。
- 继续支持项目改名或移动后的对话重关联、仅对话迁移、多个项目与对话整体迁移，以及跨电脑往返后的智能合并。
- 正式备份统一使用 `.codexchat` 与 `.codexproject`；旧 `.codexpack` 和 `.codexbundle` 只作为兼容导入格式。
- “仅对话”作为默认且靠前的备份方式；只读查看器完整显示长对话并默认定位最新消息；用户消息导航轨支持悬停预览、点击或拖动跳转，预览框随主窗口缩放。
- 批量选择项目内全部主对话后，可在同一删除流程中选择保留、移入 Windows 回收站或永久删除项目目录。
- 加强备份与导入校验，包括文件哈希、Thread ID、来源项目路径、压缩包路径、容量限制和事务回滚。
- 独立复制会生成新的 Thread ID 和独立会话文件；旧备份中“文件名编号与会话编号不一致”的记录会在导入时规范化，避免 Codex 打开后报编号不匹配。
- Codex CLI 只在删除对话和修复侧边栏残留时需要；本项目的兼容基线为 0.148.0，建议使用最新版。这不是 OpenAI 官方最低版本声明。

## Highlights

- **Native session catalog:** scans regular and archived Codex sessions, combines session metadata with the local thread index, and keeps main and subagent conversations separated by project.
- **Native formal backups:** writes `.codexchat` and `.codexproject` packages from stable snapshots, verifies the embedded Thread ID and checksum data, and replaces an existing destination package atomically only after the new package is complete.
- **Validated native import:** rejects malformed IDs, checksum mismatches, unsafe archive paths, unexpected working directories, excessive expansion, and unsupported compressed content before writing to the Codex data directory.
- **Safer merge and independent copy:** merge compares lineage and normalized metadata within the destination project; copy assigns fresh IDs, preserves parent-child relations, and normalizes the destination rollout filename.
- **Transactional recovery:** import snapshots use application-owned transaction names, are removed after commit or rollback, and retain compatibility cleanup for orphaned snapshots from earlier versions.
- **Smaller build and package:** no separate conversation-transfer executable is downloaded, built around, or included in the release ZIP.
- **Conversation viewer:** opens at the latest message, keeps long content scrollable, follows main-window resizing, and provides a Codex-style user-message rail with hover previews plus click or drag navigation.
- **Bounded archive processing:** outer packages, conversation bundles, and nested project payloads enforce entry-count, expanded-size, compression-ratio, metadata, JSONL-record, and free-space limits before writes.

## Compatibility

| Area | Requirement or behavior |
| --- | --- |
| End-user system | 64-bit Windows 10 or Windows 11 with the .NET Framework 4.8 runtime |
| Inspection, backup, and import | Built-in native engine; no Codex CLI required |
| Deletion and stale-sidebar repair | **Codex CLI 0.148.0 or later** is the project compatibility baseline; this is not an official OpenAI minimum, and the latest release is recommended |
| New formal backups | `.codexchat` for conversations and `.codexproject` for projects plus conversations |
| Legacy packages | `.codexpack` and `.codexbundle` can be imported but are not created |
| Compressed sessions | `.jsonl.zst` records can currently be listed from index metadata, but their content cannot be previewed, formally backed up, or imported |
| Source build | Windows, .NET SDK 8.x, and PowerShell 5.1 or newer; pinned NuGet reference assemblies remove the separate Targeting Pack requirement |

If a compatible CLI cannot be found or official deletion is rejected, the application preserves the original conversation. This does not prevent inspection, backup, or import through the native engine.

## Download and verification

Release assets:

- `CodexConversationMigrator-Windows-v1.0.0.zip`
- `SHA256SUMS.txt`

Verify the ZIP before extracting it:

```powershell
$zip = '.\CodexConversationMigrator-Windows-v1.0.0.zip'
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA-256 mismatch. Do not run this package.' }
$actual
```

The application EXE is not currently Authenticode-signed, so Windows SmartScreen may show an unknown-publisher warning. A matching SHA-256 hash detects a changed download but does not replace publisher identity verification.

## Upgrade and safety notes

- Extract v1.0.0 into a new folder instead of mixing it with any internal development build.
- Exit Codex completely before formal import, deletion, restoration, or stale-sidebar repair so the running client cannot overwrite updated local state.
- Keep the source package until imported conversations have been opened and verified in the destination Codex client.
- Formal backups and app-trash records are not encrypted and may contain complete prompts, source code, command output, local paths, environment details, and secrets.
- App trash is recoverable but remains inside the Codex data directory. Permanently purge confirmed-unneeded records to reclaim that disk space.
- Project packages preserve ordinary files, empty directories, and last-write timestamps, but skip directory junctions and symbolic links and do not transfer NTFS permissions or alternate data streams.
