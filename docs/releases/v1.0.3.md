# Codex Conversation Manager v1.0.3

Version 1.0.3 simplifies conversation preview and makes its spacing consistent at every main-window size.

## Changes

- Conversation preview now has one automatic layout: it opens nearly full-size and keeps the same 16-pixel outer inset as the main window is resized or maximized.
- The preview-only maximize, drag, and edge-resize controls have been removed, eliminating two competing window states.
- Message content now uses the available width with fixed inner margins, so wide screens no longer create progressively larger empty side areas.
- The vertical scrollbar reaches the content boundary cleanly and its thumb remains fully visible at the bottom of long conversations.
- The main window now respects the active monitor work area, keeping the preview footer and **Copy Thread ID** action above the Windows taskbar.
- The user-message navigation rail uses the available preview height and continues to track long conversations.
- Added Chinese and English regression renders for normal, resized, maximized-main-window, subagent, and long-conversation states.

## Compatibility

- End-user system: 64-bit Windows 10 or Windows 11 with .NET Framework 4.8.
- Inspection, preview, backup, and import use the built-in native engine and do not require Codex CLI.
- Conversation deletion and stale-sidebar repair require **Codex CLI 0.148.0 or later**; the latest compatible release is recommended.
- Existing `.codexchat`, `.codexproject`, `.codexpack`, and `.codexbundle` files remain compatible.

## Download and verification

Download both release assets:

- `CodexConversationManager-Windows-v1.0.3.zip`
- `SHA256SUMS.txt`

Verify the ZIP before extracting it:

```powershell
$zip = '.\CodexConversationManager-Windows-v1.0.3.zip'
$expected = ((Get-Content .\SHA256SUMS.txt -Raw).Trim() -split '\s+')[0]
$actual = (Get-FileHash -LiteralPath $zip -Algorithm SHA256).Hash
if ($actual -ne $expected) { throw 'SHA-256 mismatch. Do not run this package.' }
$actual
```

Extract the package into a new folder. The application is portable and unsigned; Windows may display an unknown-publisher warning.
